# Exchange

Корпоративная почта Microsoft Exchange через EWS: письма, календарь, адресная книга, отправка писем и приглашений с подтверждением.

## Навыки пакета

| Навык | Версия | Что делает | Инструменты |
|---|---|---|---|
| Exchange: серверы | 1.0.2 | Справочник серверов Exchange, текущий сервер для всех чатов, вход Windows или логином и паролем, проверка связи с EWS | `ex_system` (запись), `ex_check` (чтение) |
| Exchange: почта | 1.0.2 | Поиск и чтение писем в корпоративной почте Exchange: папки, отбор по отправителю, теме, датам, текст писем без цитат, вложения. Только чтение | `ex_folders` (чтение), `ex_mail_find` (чтение), `ex_mail_get` (чтение), `ex_attachment` (запись) |
| Exchange: календарь | 1.0.2 | Календарь Exchange: встречи за период, подробности встречи, занятость коллег и общие свободные окна, переговорные. Только чтение | `ex_calendar` (чтение), `ex_event_get` (чтение), `ex_availability` (чтение), `ex_rooms` (чтение) |
| Exchange: адресная книга | 1.0.2 | Адресная книга Exchange: поиск сотрудников по имени, адреса, должности, телефоны, руководитель, состав списков рассылки. Только чтение | `ex_people` (чтение), `ex_group` (чтение) |
| Exchange: отправка | 1.0.2 | Отправка писем, ответы, пересылка и приглашения на встречи через Exchange. Каждое действие — только после подтверждения пользователя в окне | `ex_mail_send` (запись), `ex_meeting_create` (запись) |

Пакет 1.0.0, архив `exchange-1.0.0.json`. Из поставки ставятся отмеченные навыки, импортом архива — все навыки пакета.

## Данные

- «Exchange: серверы» (ключи `ex.*`): Справочник серверов Exchange, текущий сервер и владелец ящика. Все записи личные, при переносе навыка не выгружаются.

## Важно знать

- Справочник серверов и текущий сервер хранятся в памяти агента: ex.systems, ex.current (один текущий сервер на весь агент). Любой инструмент пакета при первом вызове сам спросит сервер формой.
- Запросы идут методом POST к Exchange Web Services (адрес вида https://сервер/EWS/Exchange.asmx) через локальный хост. Вход Windows (SSO) нужен Java-прокси, сопряжённый с агентом, сервер Exchange в его allowlist и отметка «Разрешить SSO» в «Настройки → Локальный хост». Если Exchange не принимает Kerberos, в config.properties прокси нужен sso.allowNtlm=true. Вход логином и паролем: пароль вводится в окне приложения при первом запросе и хранится зашифрованным, в резервную копию не попадает; адрес должен быть https.
- Чтение ничего не меняет в ящике: письма не помечаются прочитанными. Отправка письма и приглашения идёт только после подтверждения в окне, где пользователь видит и правит адресатов и текст.
- Нужен Exchange 2010 SP2 или новее (2013, 2016, 2019) с включёнными Exchange Web Services.
- Навыкам пакета нужна сборка Camomile r36 с папкой content и входом по паролю для инструментов (agent_secret) или новее.

## После установки

Навыки и инструменты пакета подписаны разработчиком. Код инструментов не показывается и не меняется, отметка «Код проверен» не нужна. Навыки пакета можно смотреть и включать в чатах, но не менять. Новая версия ставится из поставки.

Включите нужный навык в чате. Запуск инструмента подтверждается по его категории: чтение в режиме «Оптимальный» идёт без вопросов, удаление подтверждается во всех режимах, кроме «Отключено».
