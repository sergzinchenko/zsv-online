Файлы архива могут иметь одинаковое расширение .json, но разные назначения. Открывайте их соответствующим способом. Данные экспорта могут содержать текст переписки, результаты инструментов или код собственных инструментов.

Экспортировать и импортировать один чат#

  1. Откройте чат и нажмите «Экспорт чата» внизу левой панели.
  2. Выберите «Формат файла» и решите, включать ли вызовы инструментов и результаты.
  3. Нажмите «Скачать файл».

HTML открывается в браузере, Markdown — в текстовом редакторе. Excel-экспорт переписки представляет собой таблицу с расширением .xls; Excel может предупредить о соответствии формата расширению. Для восстановления выбирайте JSON.

Для импорта выберите папку в «Чатах», нажмите «Импорт чата», укажите JSON-файл и при желании новое название. Нажмите «Загрузить чат». Проверьте появившийся разговор. Подключения моделей и сервисов такой файл не заменяет.

Перенести несколько чатов#

  1. Нажмите «Экспорт чатов».
  2. Проверьте отмеченные чаты: выбор папки влияет на начальные отметки, но список можно изменить.
  3. При необходимости отметьте «Зашифровать архив паролем», введите и повторите пароль от 8 символов.
  4. Нажмите «Скачать архив».

Для загрузки нажмите «Импорт чатов», выберите файл и режим. «Добавить» пропускает чаты с уже существующими идентификаторами; «Перезаписать» заменяет совпадающие чаты. Если архив зашифрован, введите пароль и нажмите «Загрузить».

Совпадение определяется идентификатором, а не названием. Перед перезаписью сделайте копию текущего состояния. Без шифрования архив читается как обычный JSON.

Перенести инструменты, навыки или промпты#

  1. Откройте соответствующий раздел и нужную папку.
  2. Нажмите «Экспорт» в шапке раздела.
  3. Выберите охват: текущая папка, папка со вложенными или весь раздел.
  4. Отметьте объекты, введите и повторите пароль, нажмите «Скачать зашифрованный архив».

Папки выбранных объектов сохраняются вместе с родителями. Токены MCP из записей инструментов исключаются; для переноса настроек сервера и его доступа используйте резервную копию. Не рассчитывайте, что экспорт одного раздела переносит связанные объекты из других разделов.

Для импорта откройте тот же раздел, нажмите «Импорт», выберите файл и введите пароль. Выберите добавление либо перезапись по идентификаторам и нажмите «Расшифровать и импортировать». Проверьте итоговый счётчик, папки и связи навыков с инструментами. Импортированные навыки не включаются автоматически в чатах; собственный код требует проверки.

Поставить готовый навык#

В папке content поставки лежат готовые навыки с инструментами: архивы и памятка README.md с паролями и составом. Они выходят отдельно от релизов приложения.

  1. В разделе «Навыки» нажмите «Импорт», выберите архив и введите пароль из памятки.
  2. В разделе «Инструменты» нажмите «Импорт» и выберите тот же архив. Если начать с инструментов, приложение предложит отнести их к новому навыку.
  3. Откройте инструменты навыка, прочитайте код и отметьте «Код проверен».
  4. Включите навык в чате.

Новая версия навыка ставится так же, с перезаписью по идентификаторам. После обновления код инструментов проверяется заново.

Сделать резервную копию#

  1. Сохраните незавершённые изменения настроек.
  2. Откройте «Настройки → Резервная копия → Сделать копию».
  3. Выберите состав. Для полного переноса оставьте отмеченными все части.
  4. Решите, оставлять ли «Включить ключи доступа». Без этой отметки доступы придётся ввести заново.
  5. Введите и повторите пароль от 8 символов. Сохраните его отдельно от копии.
  6. Нажмите «Скачать копию». Найдите файл ai-agent-backup-….json в загрузках.

Копия шифруется и при отключённом включении ключей. Без пароля открыть её нельзя. Для проверки восстановления используйте отдельный браузерный профиль.

В копию не входят исходные файлы с диска, сохранённые браузером разрешения, токен сопряжения с хостом, пароли входов, сохранённые для своих инструментов, и журнал незавершённого хода. Сохранённые данные зависят от выбранных частей.

Восстановить из копии#

  1. На первом запуске выберите «Восстановить из файла», либо откройте «Настройки → Резервная копия → Восстановить из копии».
  2. Укажите «Файл копии (.json)» и «Пароль копии».
  3. Нажмите «Открыть копию». Проверьте сведения и список частей.
  4. Отметьте, что вернуть.
  5. Выберите «Добавить недостающее, существующее не менять» или «Заменить совпадающие записи содержимым копии».
  6. Оставьте «Считать код инструментов проверенным» выключенным, если не проверяли этот код.
  7. Нажмите «Восстановить» и прочитайте отчёт. После перезагрузки проверьте состояние агента.

Замена совпадающих записей не означает удаление всех остальных данных. Защищённые системные инструменты и навыки не заменяются обычными объектами из копии.

Проверить результат переноса#

  • Имя и настройки соответствуют выбранным частям.
  • Нужные чаты, инструменты, навыки и промпты появились.
  • Провайдеры и модели доступны; если ключи исключались, они введены заново.
  • В тестовом чате модель отвечает.
  • В «Файлах» нужные исходники подключены кнопкой «Перевыбрать» и открываются в просмотре.
  • Если нужен локальный хост, он заново сопряжён на этом компьютере.
  • Связи навыков, доступность инструментов и отметка проверки собственного кода проверены.

При ошибке пароля проверьте раскладку и выбранный файл. Не изменяйте исходную копию вручную. Дополнительная диагностика.
