Оглавление · Безопасность

Откройте ⚙ «Настройки». В таблицах указаны значения новой установки r36. Существующий профиль и восстановленная копия сохраняют свои настройки. Изменения применяются кнопкой «Сохранить».

Ограничения одного ответа#

Один ответ включает запросы модели и связанные действия инструментов. Ожидание подтверждения пользователя и пауза учитываются отдельно от рабочего времени.

ПолеПо умолчаниюНазначение
«Максимум итераций с вызовом инструментов»25Ограничивает последовательные циклы работы модели
«Бюджет времени на ответ, секунд»180Предел времени работы над одним ответом
«Таймаут одного вызова инструмента, секунд»30Предел ожидания отдельного инструмента
«Максимум вызовов инструментов за ответ»50Общий предел вызовов
«Предел ответа инструмента, символов»20 000Ограничивает объём внешнего результата в контексте
«Сжимать начало переписки, когда она не помещается»ВключеноСоздаёт резюме начала вместо его исключения из запроса; требует дополнительного запроса модели
«Максимум шагов внутри подзадачи»10Отдельный предел черновой работы в подзадаче
«Выносить результат в артефакт от, символов»2 000Большие результаты сохраняются отдельно; модель получает описание и может читать части

0 снимает предел времени, числа итераций или общего числа вызовов. Для порога артефактов 0 отключает вынос результатов. Это правило не распространяется на все числовые поля: учитывайте допустимый диапазон формы. Раздел «Проверка ограничений» помогает обнаружить противоречивые сочетания.

В «Провайдерах и моделях» порог «Предупреждать при заполнении контекста, %» по умолчанию равен 75. Сам размер окна задаётся у модели.

Полный перечень файлов занимает контекст и может содержать чувствительные имена. При любом варианте агент может получить список инструментом, если он доступен и задача этого требует.

Безопасность и журналы#

Исходный режим — «Оптимальный». «Потолок изменений за один ответ» — 20, «Потолок вызовов одного инструмента за ответ» — 25. Они действуют вместе с ограничениями выше.

Подробные запросы/ответы LLM и вызовы инструментов в консоли по умолчанию выключены. Они нужны для диагностики и могут включать пользовательское содержимое.

«Сделать копию», «Восстановить из копии» и редакторы подключений открывают свои окна. Сначала сохраните прочие изменения настроек.
