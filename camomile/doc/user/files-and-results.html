Оглавление · Безопасность данных · Решение проблем

Добавленный файл остаётся на диске. Приложение сохраняет ссылку и сведения о нём, а содержимое читает по необходимости. Если агент прочитает файл для задачи, полученный текст может попасть в историю, артефакты и запрос к модели.

Подключить файл#

  1. Откройте «Файлы» и выберите папку для ссылки.
  2. Нажмите «Добавить файлы».
  3. В окне браузера выберите файл, например meeting.txt, предварительно сохранённый на компьютер.
  4. Нажмите «Просмотр» в карточке и при запросе разрешите чтение.

Результат: карточка показывает имя, размер, формат и состояние. Для учебного текста в просмотре видны три пункта встречи. «Заметка» позволяет указать назначение файла; «Убрать» удаляет только ссылку, исходный файл остаётся на диске.

Попросить агента прочитать файл#

  1. Убедитесь в разделе «Файлы», что файл доступен.
  2. Вернитесь в нужный чат, нажмите «все навыки» и включите навык «Файлы». Через ⚙ проверьте доступность чтения.
  3. Напишите: Прочитай подключённый файл meeting.txt. Перечисли темы встречи и ответственных. Ничего не изменяй в файле.
  4. При запросе подтверждения проверьте имя файла и действие, затем примите решение.

Ожидаемый результат: агент перечислит план работ — Анна, сроки — Борис, риски — Вера. Если одинаковых имён несколько, уточните папку или заметку. Вставленный в сообщение путь к файлу сам по себе не даёт браузеру доступа к диску.

Что означает состояние карточки#

СостояниеДействие
«связан»Ссылка доступна, можно открыть «Просмотр»
«нужно разрешение»Нажмите «Восстановить доступ» над списком и подтвердите запросы браузера; либо откройте «Просмотр»
«требуется повторный выбор»Нажмите «Перевыбрать» и укажите нужный файл

Повторный выбор нужен после переноса резервной копии, перемещения файла или работы в браузере без постоянных ссылок. Он заменяет файл, на который указывает карточка; выбирайте правильный исходник.

В Chrome/Edge при доступном выборе файлов ссылка может сохраняться между запусками, но браузер вправе запросить разрешение снова. В запасном режиме файл доступен только до перезагрузки страницы.

Какие данные можно прочитать#

ТипДоступный результат
Текст, Markdown, CSV, JSON и другие текстовые файлыТекст; для больших файлов агент может читать части
DOCX, XLSX, PPTX, ODF, EPUBИзвлечённый текст или табличные данные; оформление документа не сохраняется полностью
PDFПриблизительное извлечение текста; некоторые документы не читаются, распознавание сканов не предусмотрено
ИзображенияСведения о формате и размере, просмотр; это не обещание распознавания содержимого любой моделью
Архивы и другие двоичные файлыСостав поддерживаемого архива или сведения о формате и байтах

Если PDF читается неполно, сохраните нужный фрагмент в текстовый файл или используйте экспорт из исходного приложения. Для первой проверки таблиц есть sales.csv.

Скачать подготовленный результат#

Укажите в запросе желаемый формат, например: Сделай краткий итог встречи и подготовь файл summary.txt для скачивания. Включите соответствующий навык, если он нужен для выдачи файла.

Результат может появиться ссылкой скачивания или карточкой артефакта. Используйте «Показать»/просмотр для поддерживаемого типа и «Скачать» для сохранения. Затем откройте скачанный файл и проверьте содержимое. Текст ответа в чате без ссылки ещё не означает, что создан файл на диске.

Если агент предлагает комплект файлов, можно выбрать папку в поддерживаемом браузере или скачать архив. Сохранение в папку может перезаписать совпадающие имена.

Сохранить изменения в исходном файле#

Для записи нужен поддерживаемый браузером доступ к файлу. Перед первой правкой сделайте копию исходника.

  1. Подключите файл и явно попросите изменить его, указав нужные изменения.
  2. В окне «Изменить файл?» проверьте имя и показанные различия.
  3. Нажмите «Записать» либо «Не записывать».
  4. Если браузер отдельно попросит разрешение на изменение, подтвердите его только для выбранного файла.
  5. Проверьте файл на диске.

Подтверждение записи не заменяет разрешение браузера. Запись перезаписывает исходник, отмены из приложения нет. Если доступна только загрузка через обычное окно выбора, используйте скачивание новой версии.
