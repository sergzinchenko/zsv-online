Пакет Naumen SD даёт агенту чтение данных Naumen Service Desk через REST API: заявки, сотрудники, отделы и другие объекты. Ничего не создаётся и не меняется.

Как поставить навыки и что для них нужно: Дополнительные навыки.

Навыки пакета#

НавыкЧто делает агент
«Naumen SD: серверы»Ведёт справочник серверов, переключает текущий сервер, проверяет связь
«Naumen SD: чтение данных»Ищет объекты по классу и значениям атрибутов, читает объект по идентификатору
«Naumen SD: исследование и знания»Разбирает незнакомый класс по образцам, запоминает выясненное о сервере и пользуется им дальше, считает сводки по значениям

Запись сервера#

Поля формы «Сервер Naumen SD»:

  • «Имя сервера»: короткое имя, например main или test.
  • «Адрес Naumen»: адрес приложения вида https://sd.example.local/sd. Можно вставить ссылку на любую страницу Naumen: лишнее обрежется.
  • «Вход»: «Вход Windows (SSO) через локальный хост» или «Логин и пароль Naumen». Вход паролем работает только по https.

Ключ доступа Naumen (accessKey) не используется.

Что спросить#

  • «Проверь подключение к Naumen».
  • «Найди закрытые заявки и покажи номер, тему и ответственного».
  • «Найди заявку с номером 12345 и покажи её описание».
  • «Сколько заявок в каждом состоянии?»
  • «Разберись, в каком атрибуте заявки хранится ответственный, и запомни».
  • «Что ты знаешь о заявках?», «Какие приоритеты есть в Naumen?».
  • «Запомни запрос: открытые заявки команды» и затем «Покажи открытые заявки команды поддержки».
  • «Собери справочник услуг».
  • «Забудь всё, что запомнил об отделах».

Как агент читает данные#

  • Объект заявки в Naumen содержит около 400 атрибутов. Агент читает только нужные атрибуты и получает сжатый ответ: без пустых полей, ссылки на объекты показаны названием и идентификатором.
  • Коды атрибутов и классов у каждой установки свои. Незнакомый класс агент разбирает по нескольким образцам и запоминает выясненное: см. «Что агент запоминает».
  • Поиск сравнивает значения точно, без масок и диапазонов. Ссылку на объект агент передаёт идентификатором (employee$123), состояние — кодом (registered).
  • На вопросы «сколько» агент отвечает сводкой по значениям атрибута. Если прочитаны не все объекты, он скажет, что число неполное.

Что агент запоминает#

Выясненное о сервере хранится в памяти агента, общее для всех чатов, и сохраняется при обновлении навыков. Его видно на вкладке «Память» в разделе «Naumen SD: серверы и знания».

ЧтоКак пополняетсяКак используется
Знания о классе (sd.kb.<класс>): название, типы, атрибуты по умолчанию, смысл атрибутов, рецепты запросов, заметкаАгент записывает, когда что-то выяснил или вы попросили запомнитьПоиск читает атрибуты по умолчанию и выполняет рецепты, в ответе атрибуты подписаны названиями
Справочники значений (sd.dict.<класс>): приоритеты, срочность, услуги, команды, отделыЭлементы с кодом (приоритет, срочность, папки) запоминаются сами при чтении. Другие справочники — после того как агент отметил атрибут справочником или собрал его по вашей просьбеВ условии поиска можно назвать значение словами: агент сам подставит идентификатор. Если название неоднозначно, агент покажет варианты
Состав атрибутов класса (sd.schema.<класс>): вид значения и заполненность, без самих значенийСам, при разборе класса по образцамАгенту не нужно заново читать образцы, чтобы вспомнить состав класса

Рецепт — удачный запрос под типовой вопрос, например «открытые заявки команды». Агент сохраняет его с местами для подстановки и в следующий раз выполняет одним вызовом.

Чего агент не запоминает: сотрудников, заявки и записи истории, тексты обращений. В заметках и описаниях атрибутов только устройство данных.

Профили классов прежних версий (sd.profiles) переезжают в знания о классах сами. Чтобы что-то забыть, попросите агента или удалите запись на вкладке «Память». При экспорте навыка знания, справочники и состав атрибутов можно взять с собой: они отмечены «переносится», справочник серверов не выгружается.

Знания относятся к одной установке Naumen. Если в справочнике серверов есть серверы разных установок, после переключения сервера попросите агента проверить знания на новом сервере.

Чего нет#

  • Создание и изменение заявок.
  • Работа через интерфейс Naumen (страницы оператора): доступен только REST API.

Если не работает#

Что видноЧто сделать
403У учётной записи нет прав на этот класс объектов или на REST API
404Неверный класс или идентификатор. Если не находится ничего, проверьте адрес сервера
400 с текстом NaumenНеверный код атрибута или вид значения. После двух ошибок подряд агент останавливается и показывает текст ошибки
«Ответ Naumen не разбирается как JSON»Адрес ведёт не на REST API. Проверьте, что он вида https://сервер/sd
